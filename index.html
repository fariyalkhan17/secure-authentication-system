🔐 Built-In Security Features

  • 🛡️
    Bcrypt Password Hashing

    Passwords salted and hashed with cost factor 12. Plaintext never touches the database.

  • 💉
    SQL Injection Defense

    100% Parameterized prepared statements (`SELECT * FROM users WHERE email = ?`).

  • 🧪
    Input Sanitization & XSS Defense

    Server-side `express-validator` HTML escaping and strict Content Security Policy (CSP).

  • 🍪
    HttpOnly & SameSite Sessions

    Session tokens stored in SQLite DB. Cookies marked `HttpOnly` to prevent JS theft.

  • ⏱️
    Rate Limiting & Brute-Force Block

    Max 5 auth requests per 15 min window to halt credential stuffing.
